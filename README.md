# Aunty Hong — design demo

A redesigned storefront for Aunty Hong. Catalogue, cart, checkout, demo PayNow, and a kitchen admin desk.

This is not the live shop. It does not take real money and must not replace auntyhong.sg.

Shop: http://localhost:3000
Kitchen desk: http://localhost:3000/admin
Default admin password: auntyhong-demo

Demo voucher: WELCOME10 (10% off).
Minimum online order: S$50 (editable in kitchen settings).
